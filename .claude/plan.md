# PhotoLib 代码审计计划

## 项目概述

PhotoLib 是一个面向公众号摄影部的图片工作站系统，技术栈：
- **前端**: React 19 + TypeScript + Vite 7 + Ant Design 6
- **后端**: Java 21 + Spring Boot 4 + Spring Security + MyBatis-Plus
- **数据库**: MySQL 8 + Flyway 迁移
- **存储**: 阿里云 OSS / 本地文件存储
- **通知**: 阿里云 DirectMail

## 审计范围

### 1. 安全审计
- **认证与授权**
  - 审查访问令牌与刷新令牌实现
  - 检查密码存储与处理
  - 验证会话管理机制
  - 检查 @PreAuthorize 注解的覆盖情况
  - 验证首次登录强制改密逻辑
  
- **输入验证**
  - 检查所有 Controller 层的输入验证
  - 验证文件上传验证逻辑（类型、大小、哈希）
  - SQL 注入防护（MyBatis-Plus 参数化查询）
  - XSS 防护
  
- **数据安全**
  - 敏感信息处理（密码、AccessKey、令牌）
  - 预签名 URL 的安全性
  - 文件访问控制
  - 审计日志完整性

- **配置安全**
  - 检查默认密码和配置
  - CORS 配置
  - CSRF 保护（已禁用，需验证合理性）
  - Cookie 安全属性

### 2. 代码质量审计
- **架构设计**
  - 分层架构合理性
  - 依赖注入使用
  - 事务管理
  
- **错误处理**
  - 异常处理机制
  - 错误信息敏感度
  - 日志记录
  
- **代码规范**
  - 命名规范
  - 代码重复
  - 复杂度
  - 注释文档

### 3. 性能与可靠性
- **数据库**
  - 索引设计
  - N+1 查询问题
  - 分页实现
  
- **并发控制**
  - 乐观锁使用
  - 事务隔离级别
  - 竞态条件
  
- **资源管理**
  - 文件流关闭
  - 连接池配置
  - 内存使用

### 4. 业务逻辑
- **状态流转**
  - 项目/需求/照片状态机
  - 工时确认流程
  
- **数据一致性**
  - 逻辑删除实现
  - 版本号机制
  - 外键约束

### 5. 测试覆盖
- 单元测试覆盖率（当前仅 6 个测试文件）
- 集成测试质量
- 关键业务场景测试

### 6. 前端安全
- XSS 防护
- 敏感数据存储（localStorage）
- API 调用安全
- 路由保护

## 审计方法

1. **静态代码分析**: 审查源代码，识别潜在安全漏洞和质量问题
2. **配置审查**: 检查配置文件中的安全设置
3. **依赖审查**: 检查第三方依赖的已知漏洞
4. **架构评审**: 评估系统设计的合理性
5. **最佳实践对比**: 对比行业最佳实践

## 输出

生成包含以下内容的审计报告（REVIEW.md）：
- 执行摘要
- 严重问题清单（按优先级）
- 详细发现（分类说明）
- 改进建议
- 代码质量评分
- 合规性检查
