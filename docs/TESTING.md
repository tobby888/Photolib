# 前端专项测试用例

## 测试范围

本次仅补充管理员自定义面板 Slogan 和图标的测试，不包含账号、校区及其他业务功能。

## 前置条件

- 前端与后端服务均已启动。
- 使用管理员账号登录。
- 打开“系统管理 > 面板品牌”。

## 用例

### BRAND-01 自定义 Slogan

1. 保持当前图标不变。
2. 将 Slogan 修改为“记录校园每一刻”。
3. 点击“保存品牌设置”。
4. 检查左侧导航栏。
5. 刷新页面并再次检查左侧导航栏。

预期结果：

- 保存成功后，左侧导航栏立即显示“记录校园每一刻”。
- 刷新页面后仍显示该 Slogan，证明配置已持久化。

### BRAND-02 自定义图标

1. 保持当前 Slogan 不变。
2. 将面板图标从“相机”修改为“星标”。
3. 点击“保存品牌设置”。
4. 检查左侧导航栏品牌图标。
5. 刷新页面并再次检查品牌图标。

预期结果：

- 保存成功后，左侧导航栏立即显示星标图标。
- 刷新页面后仍显示星标图标，证明配置已持久化。
