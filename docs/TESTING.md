# 前端专项测试用例

## 测试范围

本次仅补充管理员自定义面板品牌名称、Slogan 和图标的测试，不包含账号、校区及其他业务功能。

## 前置条件

- 前端与后端服务均已启动。
- 使用管理员账号登录。
- 打开“系统管理 > 面板品牌”。

## 用例

### BRAND-01 自定义品牌名称与 Slogan

1. 保持当前图标不变。
2. 将品牌名称从“PhotoLib”修改为“校园影像库”。
3. 将 Slogan 从“摄影工作站”修改为“记录校园每一刻”。
4. 点击“保存品牌设置”。
5. 检查左侧导航栏。
6. 刷新页面并再次检查左侧导航栏。

预期结果：

- 保存成功后，左侧导航栏上方大字立即显示“校园影像库”。
- 下方小字立即显示“记录校园每一刻”。
- 刷新页面后两个文案均保持不变，证明配置已持久化。

### BRAND-02 使用系统内置图标

1. 保持当前品牌名称与 Slogan 不变。
2. 将面板图标选择为“星标”。
3. 点击“保存品牌设置”。
4. 检查左侧导航栏。
5. 刷新页面并再次检查左侧导航栏。

预期结果：

- 保存成功后，左侧导航栏立即显示星标图标。
- 刷新页面后仍显示星标图标。

### BRAND-03 上传自定义图片图标

1. 准备一张 64 × 64 像素的 PNG 图片，文件大小不超过 512 KB。
2. 点击“选择图片并上传”并选择该图片。
3. 检查左侧导航栏品牌图标和设置页预览。
4. 刷新页面并再次检查品牌图标。

预期结果：

- 上传成功后自动启用自定义图片，侧栏与设置页均正确显示。
- 刷新页面后仍显示该图片。
- 前后端只接受 PNG、JPEG，文件不超过 512 KB，图片尺寸不超过 1024 × 1024 像素。
