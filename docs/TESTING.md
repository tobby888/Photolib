# 前端专项测试用例

## 测试范围

本文覆盖管理员自定义品牌设置、站点定制（登录页文案、全站页脚、缺图占位图），
以及表格内容自适应和窄屏横向滚动专项测试。

## 前置条件

- 前端与后端服务均已启动。
- 使用管理员账号登录。
- 品牌用例打开“系统管理 > 面板品牌”，站点定制用例打开“系统管理 > 页面定制”；表格用例按步骤进入对应页面。

## 用例

### BRAND-01 自定义品牌名称与 Slogan

1. 保持当前图标不变。
2. 将品牌名称从“PhotoLib”修改为“校园影像库”。
3. 将 Slogan 从“摄影工作站”修改为“记录校园每一刻”。
4. 点击“保存品牌设置”。
5. 检查左侧导航栏。
6. 刷新页面并再次检查左侧导航栏。

预期结果：

- 保存成功后，左侧导航栏上方大字立即显示“校园影像库”。
- 下方小字立即显示“记录校园每一刻”。
- 刷新页面后两个文案均保持不变，证明配置已持久化。

### BRAND-02 使用系统内置图标

1. 保持当前品牌名称与 Slogan 不变。
2. 将面板图标选择为“星标”。
3. 点击“保存品牌设置”。
4. 检查左侧导航栏。
5. 刷新页面并再次检查左侧导航栏。

预期结果：

- 保存成功后，左侧导航栏立即显示星标图标。
- 刷新页面后仍显示星标图标。

### BRAND-03 上传自定义图片图标

1. 准备一张 64 × 64 像素的 PNG 图片，文件大小不超过 512 KB。
2. 点击“选择图片并上传”并选择该图片。
3. 检查左侧导航栏品牌图标和设置页预览。
4. 刷新页面并再次检查品牌图标。

预期结果：

- 上传成功后自动启用自定义图片，侧栏与设置页均正确显示。
- 刷新页面后仍显示该图片。
- 前后端只接受 PNG、JPEG，文件不超过 512 KB，图片尺寸不超过 1024 × 1024 像素。

### SITE-01 登录页文案

1. 在“页面定制”里修改登录页主标题（写成两行）、副标题、关键词和底部提示，点击“保存页面定制”。
2. 退出登录，打开登录页。
3. 回到“页面定制”，把主标题和底部提示清空后再次保存，重新打开登录页。

预期结果：

- 登录页左侧大标题按两行显示，副标题和关键词与配置一致，登录卡片下方显示配置的提示语。
- 清空之后，对应区块整块消失，页面不出现空白占位，也不会退回旧的写死文案。

### SITE-02 全站页脚

1. 在“页面定制”里填写页脚文案，并添加两条链接（一条 `https://` 外链，一条站内 `#/docs`）。
2. 保存后依次查看：工作台任意页面、登录页、公开招募页 `#/recruitment`、文档中心 `#/docs`。
3. 用非管理员账号（部长、校区负责人）登录，再次查看工作台。
4. 尝试把某条链接地址改成 `javascript:alert(1)` 并保存。
5. 把页脚文案和链接全部清空后保存。

预期结果：

- 四个位置都显示同一份页脚；外链在新标签打开，站内链接在当前页跳转。
- 非管理员角色同样看到页脚。
- 第 4 步保存失败并提示地址只支持 http://、https://、mailto: 或站内 #/ 开头。
- 全部清空后页脚整块消失，页面底部不留空白横条。

### SITE-03 缺图占位图

1. 在“页面定制 > 缺图占位图”上传 3 张明显不同的图片。
2. 打开图片库，观察没有预览图的图片、以及预览图取不回来的图片（可临时断开对象存储或让签名过期）。
3. 反复刷新图片库，观察同一张图片对应的占位图。
4. 打开“好图精选”里一条图片已被删除的记录。
5. 删除全部占位图后再次打开图片库。

预期结果：

- 缺图位置显示上传的占位图，不同图片会用到不同的占位图。
- 同一张图片每次刷新都用同一张占位图，不会来回换。
- 已删除的精选图片仍然在占位图上显示“图片已从图库删除”。
- 占位图清空后回到内置的灰底占位，界面不报错。

### TABLE-01 表格内容自适应与响应式操作列

1. 分别在 1280、768、375 和 320 像素宽度下检查“工时管理”“图片需求”“系统管理 > 账号管理”“系统管理 > 权限管理”和“通讯录”。
2. 工时页覆盖普通用户“提交 + 删除”和审核者“批准 + 退回 + 删除”两种操作组合。
3. 图片需求页使用校区权限下的待确认数据，覆盖“交付图片 + 打回 + 确认完成 + 关闭 + 删除”的最长组合。
4. 账号、权限组和通讯录使用长中文姓名、长账号及多校区数据。
5. 横向滚动各表格到最左和最右，检查操作列及相邻列。

预期结果：

- 按钮、图标和开关完全位于“操作”单元格内，不覆盖相邻列，也不被单元格裁切。
- 窄屏只在表格自身出现横向滚动，页面不产生额外的横向滚动条。
- 1280 像素下操作列停靠在表格右侧；768、375 和 320 像素下操作列取消固定，可通过表格横向滚动完整查看。
- 工时说明、请求 ID 和需求摘要等明确限制宽度的自由文本显示省略号，并可通过悬停标题查看完整值。
